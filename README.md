# sugarshock

A showcase of little helpers for [SugarCube 2](https://www.motoslave.net/sugarcube/2/), see the [demo story](https://spectreforge.github.io/sugarshock/).

## Packages

- [`@spectreforge/sugarcube-hotkey`](packages/hotkey): configurable keyboard shortcuts for SugarCube 2 stories
- [`@spectreforge/tiny-jsx2dom`](packages/tiny-jsx2dom): minimal JSX-to-DOM runtime (private)
